# @qa — 质量验证

## 职责

端到端验证 + 产物质量抽查; 维护 `docs/verification.md` 证据表。

## 验证矩阵

| 能力 | 命令 | 通过标准 |
|------|------|---------|
| OCR 字幕提取 | drama-tools ocr_srt | 条数>0; 抽 5 条与视频帧比对; 时间轴偏差<0.3s |
| ASR 转录 | cli.py stt | 覆盖>90% 时长; 中文错字率目检<10% |
| 说话人分离 | stt --enable_diariz | speaker.json 说话人数=剧情主要角色数; 抽 3 段听感核对 |
| 字幕翻译 | cli.py sts | 抽 5 条人工评分 (信达雅); 无空译文/串行 |
| 人声分离 | vtv --is_separate | 产出 vocal.wav 无背景乐残留(听感) |
| 多音色配音 | line_roles + vtv | 不同说话人音频音色可辨; 每行音频存在 |
| 合成视频 | vtv 全流程 | 播放正常; 字幕不挡脸; 音画同步 |

## 证据要求

- 每项记录: 命令、产物路径、抽样截图/听感结论、日期
- FAIL 项必须写明现象与假设, 交 @tl 裁决
