# 短剧硬字幕 OCR 提取

## 何时使用

- 视频内嵌(烧录)中文字幕, 需要**无声提取**或与 ASR 结果互补校验
- 竖屏短剧 (720x1280) 字幕位置常在 y≈0.59-0.71, 与横屏 (0.75-0.95) 不同 → 必须 auto 标定

## 用法

```bash
cd "/Users/mac/Documents/project/py videos/drama-tools"
uv run ocr_srt.py --input <视频绝对路径> --output <输出.srt> --debug
```

## 关键调参 (按问题现象)

| 现象 | 参数 |
|------|------|
| 字幕带定位错/混入水印 | `--region auto` (默认) 探测帧聚类; 手动指定 `--region 0.55:0.75` |
| 单字噪声碎片多 | 提高 `--min-conf 0.65`、`--min-chars 2` |
| 同一条字幕被切碎 | 降低 `--similarity 0.6`; 采样更密 `--fps 6` |
| 时间轴偏早/偏晚 | 调 `--pad 0.12` (首尾外扩秒数) |
| 识别率低 | 该剧字幕偏小 → 已内置 2x 放大; 再不行 fps 提高利用多帧投票 |

## 质量基线 (第01/02集实测)

- 42/45 条, 时间轴准确, 每条置信度>0.6, 存在少量字符级噪声 (NR/一库上/胎台气)
- 噪声修复路径: pyvideotrans `--rephrase 1` (LLM 断句纠错) 或人工抽查

## 常见坑

1. 不要传灰度图给 RapidOCR — 直接彩色帧, 引擎内部处理效果更好 (实测)
2. 顶部「影视效果 请勿模仿」类静态水印会被 auto 聚类自动排除 (唯一文本数=1 的簇)
3. 采样 fps>8 对 90s 短剧收益递减, 4-6 最佳
